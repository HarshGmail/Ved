# Icon generation

Every app icon is derived from one source file, `assets/ved-mark.png`, by
`generate-icons.py`. Edit the source and re-run; never hand-edit the outputs.

```bash
cd apps/web-client
uv run --with pillow python scripts/generate-icons.py
```

## What it emits

| Output | Used by |
| --- | --- |
| `src/app/favicon.ico` | Browser tabs, bookmarks |
| `src/app/icon.png` | `<link rel="icon">`, generated by Next |
| `src/app/apple-icon.png` | `<link rel="apple-touch-icon">`, generated by Next |
| `public/icon-{192,512}.png` | Manifest, `purpose: any` |
| `public/icon-maskable-{192,512}.png` | Manifest, `purpose: maskable` |
| `public/apple-touch-icon.png` | Older iOS that looks for the root path |

Files in `src/app/` follow Next's file conventions — dropping them there is what
makes the `<link>` tags appear, so the layout declares no `icons` metadata.
Manifest icons must be real paths under `public/`, so those are separate files
rather than the same ones reused.

## Why the variants differ

**Maskable icons are padded to 80%.** Android crops a maskable icon to a circle
or squircle of its own choosing. The artwork's ring reaches ~85% of the frame,
so feeding it in unpadded would slice the outer ticks off. The padding is pure
black to match the artwork's own background, or the seam shows.

**The favicon is cropped tighter and brightened.** At 16px the full ring
averages into an unreadable navy smudge — the bright detail sits between 20% and
60% of the radius, and the near-empty outer band just dilutes it. Cropping to
86% and lifting brightness 1.35x keeps a legible glowing ring while preserving
the round silhouette. Check any change at 16px, not at 512px.

**The `.ico` is written as RGBA.** Turbopack fails the build with "The PNG is not
in RGBA format" on an RGB-mode ICO. Pillow writes RGB by default, so the
`convert("RGBA")` is load-bearing.

## Size

The PNGs are quantized to a 128-colour palette, which is lossless to the eye on
blue-on-black line art and roughly halves the bytes. The whole set is ~620 KB
rather than ~1.4 MB, and the favicon is 10 KB rather than 214 KB — it stops at
48px because nothing consumes a 256px `.ico`, and the browser fetches it on
every page load.

If the artwork ever changes to something photographic, re-check the palette
size: 128 colours is chosen for flat glowing line work, not gradients.
